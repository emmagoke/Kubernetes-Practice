## 📌 About This Repository
This repository is my personal sandbox and daily log for mastering Kubernetes. Every day, I design, configure, and push new K8s manifests tailored to specific DevOps and cloud-native scenarios. 

**Goals:**
- Practice writing clean, production-ready YAML manifests.
- Understand deep Kubernetes architecture, networking, storage, and security.
- Document practical solutions to common infrastructure challenges.
